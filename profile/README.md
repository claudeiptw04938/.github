<p>买之前先纠正三个说法，比对比十家报价有用。共享池被当成独享家庭宽带卖，机房段被说成住宅段，按并发数计费被理解成按人头计费——这三处混淆几乎覆盖了大部分售后纠纷。下面把每个说法拆开，给出可验证的判别方法，以及弄清楚之后该换一种什么样的提问方式。</p>

<h2>一、三个最常被混用的词</h2>
<p>共享池、独享出口、家庭宽带，这三个词在中文语境里经常被交替使用，但它们指向完全不同的资源形态。共享池是多人在同一批地址里轮换，独享出口是固定一人一份，家庭宽带则是物理线路真实入户。三者的价格差能到几倍，体验差异也集中在不同维度上。</p>
<p>混淆的后果不只是多花钱，更常见的是买错类型：明明需要固定出口，买了共享池；明明只是单人低频使用，为了「独享」付了高价。</p>

<h2>二、误区一：能连上就等于独享</h2>
<p>能连上只能说明这条链路可用，与你是否独占没有关系。共享池在人数不多的时候同样稳定，延迟也正常，唯一区别在于同一地址上还有别人的流量。</p>
<h3>同一地址出现多个会话的迹象</h3>
<p>三个迹象值得注意：同一时刻同一地址的并发连接数超过你本机实际请求数；出口地址在短时间内自行变化；某些时段突然出现与你无关的限流。验证方法是在服务商提供的面板里查看当前地址的连接数，或者用两个不同网络环境同时查询出口地址，看是否会撞到同一个。</p>

<h2>三、误区二：住宅段就等于家庭宽带</h2>
<p>地址段被登记为住宅用途，不等于这条链路真的从居民家里接出来。部分服务商会把机房地址挂在住宅用途的注册信息下，或者在住宅小区附近托管设备，从注册信息上看不出差别。</p>
<h3>从路径特征识别托管段</h3>
<p>真实家宽通常要经过运营商的多层汇聚，路径跳数偏多，末段延迟会有几毫秒的起伏；托管段往往路径短、延时曲线平直，甚至第一跳就是数据中心设备。用 <code>mtr</code> 跑二十跳，看第几跳出现运营商域名、第几跳进入目标网段，比看注册信息可靠。</p>
<p>另一个角度是反向解析。真实家宽的地址往往有运营商分配的解析记录，形如带有城市或片区标识的域名；托管段的解析经常缺失或指向托管商域名。</p>

<h2>四、误区三：并发数按人头算，不按连接算</h2>
<p>计费口径的误解最容易造成超支。多数服务商的「并发」指的是同时活跃的连接数，一个浏览器标签可能占用多条连接，一个后台同步任务也可能同时开五条。按人数估算，几乎必然低估。</p>

<h2>五、换一种问法：先问自己要几个出口</h2>
<p>与其问「这是不是独享」，不如问「我需要几个互相独立的出口」。这个问法能直接推导出采购方案：一个人一套环境，就是一个出口；三个人各自独立，就是三个出口；只是同一批任务的并发提速，则一条高并发出口加合理重试更划算。</p>
<p>接着问第二个问题：「这个出口需要保持多久」。几天内完成的临时任务，动态轮换足够；需要长期保持登录状态，就必须固定出口。两个问题回答完，资源类型基本确定，剩下的只是价格比较。</p>
<h3>把两个答案写成三行需求</h3>
<p>最后再确认一句：这个价格包含的并发和流量分别是多少，超出后怎么计费。把这三个数字写进合同或聊天记录，比任何口头承诺都可靠。</p>

<h2>常见问答</h2>
<h3>共享池能不能用来长期登录同一个账号？</h3>
<p>答：不建议。地址频繁变化会让每次访问都像新设备，验证提示会增加。长期使用应选固定出口，哪怕单价更高，综合成本通常更低。</p>
<h3>怎么快速判断买的是不是共享池？</h3>
<p>答：连续十次查询出口地址，看是否变化；再看计费方式是按流量还是按月。两项都指向「会变、按流量」，基本可以判定为共享池。</p>
<h3>住宅段被识别成机房，能要求退款吗？</h3>
<p>答：取决于合同条款。多数服务商只承诺「地址可用」，不承诺用途标注。采购前把用途标注写进需求说明，并保留查询截图，出现争议时才有依据。</p>
<h3>并发超了会怎样？</h3>
<p>答：常见处理是排队、拒绝新连接，或按超出部分额外计费。表现是页面加载变慢、部分请求直接失败。发现这类现象先看面板的连接数曲线，而不是怀疑线路质量。</p>
